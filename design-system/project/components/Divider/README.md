A vertical separator line placed between components laid out horizontally. Separates groups of actions in a toolbar.

## When to use
- To split a horizontal row of buttons into meaningful groups.
- Not for: separating vertically stacked elements (a horizontal line); it cannot do that.

## Props
- None.

## Rules
- A 1px wide, 20px tall line in the `border` colour, horizontal margin `sp-1`, `flex: none`.

## Similar components
- None (there is no horizontal-line component).

Used in: `gui/src-ui/js/App.tsx`, `components/data.tsx` (`ScoreRow`), `ggs/Chat.tsx`, `ggs/Console.tsx`, `ggs/Lobby.tsx`, `ggs/Results.tsx`.
